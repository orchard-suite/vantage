A successful response uses the decide skill and plans the record in the SHOP registry. Before any code change, it plans to file the work the decision owes: it searches the SHOPR and SHOPW kinds for items that already cover the work, and writes new ones only where none does, with each work item placed under a roadmap item (`part-of`). It links the items to the record with a `decision` link. Because building starts now, it plans to claim a work item and move it to doing before the first code change. It does not leave filing the work for later. It asks who made the decision rather than guessing a name. Judge only these points; the record's category and wording are not graded.
