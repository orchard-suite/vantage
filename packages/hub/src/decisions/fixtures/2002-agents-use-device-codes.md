# 2002. Agents use device codes

## Context and Problem Statement

Tokens pasted by hand go stale. Supersedes ADR-2001.

## Considered Options

- **Pasted tokens**: they go stale.
- Browser redirect - agents run with no browser.

## Decision Outcome

Agents sign in with a device code.

### Consequences

Good, because nothing is pasted.
